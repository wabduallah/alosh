# العش — The Nest

ألعاب جماعية للعائلة. التلفزيون يعرض الجولة، والجوالات هي أزرار التحكم. حتى 14 لاعبًا في الغرفة نفسها، مع رمز وباركود.

## التشغيل على جهازك

```bash
npm install
npm run dev
```

الموقع يفتح على `http://localhost:8080`. بدون إعداد Supabase يستخدم قاعدة بيانات محلية داخل التشغيل، مناسبة للتجربة فقط. النشر على الإنترنت يحتاج Supabase.

## البناء

```bash
npm run build
```

على Cloudflare Pages يُضبط المتغير `CF_PAGES` تلقائيًا، فيخرج البناء إلى المجلد `dist` وفيه عامل `_worker.js`. هذا هو مجلد النشر.

## المتغيرات

انسخ `.env.example`. لا تضع المفاتيح السرية داخل ملفات الواجهة ولا ترفع `.env` إلى GitHub.

| المتغير | أين يُستخدم | سري؟ |
|---|---|---|
| `DATABASE_URL` | السيرفر، رابط Postgres من Supabase (Session pooler) | نعم |
| `VITE_SUPABASE_URL` | المتصفح، للمزامنة اللحظية | عام |
| `VITE_SUPABASE_ANON_KEY` | المتصفح، مفتاح anon فقط | عام |
| `STRIPE_SECRET_KEY` ومفاتيح الدفع | لاحقًا، غير مطلوبة الآن | نعم |

المتغيرات التي تبدأ بـ `VITE_` يجب أن تكون موجودة **قبل** أمر البناء، لأن Vite يكتبها داخل ملفات الموقع.

## Supabase

1. أنشئ مشروعًا مجانيًا على [supabase.com](https://supabase.com).
2. افتح SQL Editor والصق محتوى [supabase/schema.sql](supabase/schema.sql) ثم Run.
3. من Project Settings → API انسخ عنوان المشروع ومفتاح `anon`.
4. من Connect اختر **Session pooler** (المنفذ 5432) وانسخ رابط Postgres إلى `DATABASE_URL`.

المزامنة تتم عبر جدول `room_signals` وSupabase Realtime. جدول `rooms` يبقى سريًا ولا يُعرض للمتصفح.

## الروابط

تُبنى من عنوان الموقع الحالي، فتعمل على `pages.dev` أو أي دومين لاحقًا:

- `/join/CODE` دخول اللاعبين والباركود
- `/tv/CODE` شاشة التلفزيون
- `/host/CODE` نفس شاشة التلفزيون
- `/pad/CODE` و`/play/CODE` جوال اللاعب
- `/admin` لوحة التحكم

## لوحة التحكم

1. افتح `/admin`.
2. سجّل الدخول.
3. أول مرة اكتب رمز التأسيس: `LAMMA-HOST`.
4. بعدها تستطيع إدارة الألعاب والأسئلة والتصنيف والعدد المجاني أو البريميوم والقوانين.

لا يوجد دفع حقيقي الآن. الألعاب المعلّمة Premium تبقى مقفلة حتى يُضاف مزود دفع لاحقًا.
