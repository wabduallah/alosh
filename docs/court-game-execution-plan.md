# ملف تنفيذي جاهز — تطوير لعبة المحكمة (العش / al3sh.app)

**الإصدار:** 1.0  
**التاريخ:** 2026-10-14  
**الحالة:** جاهز للتنفيذ  
**النطاق:** لعبة المحكمة فقط (بدون إعادة بناء المنصة)

---

## 1) الهدف

جلسة محكمة:

- مفهومة من أول مرة
- أقل اعتمادًا على المضيف
- بأدوار أكثر توازنًا
- بقضايا مصنفة وأقوى
- بنهاية كشف درامية واضحة

**قيود ملزمة:**
- لا حذف ميزات المنصة
- لا كسر للغرف أو باقي الألعاب
- لا نشر محتوى AI بدون مراجعة
- أي تعديل على قاعدة البيانات إضافي ومتوافق رجعيًا

## 2) معايير النجاح

## 3) المراحل التنفيذية

### المرحلة 0 — التدقيق (يوم 1–2)
- [ ] جرد state machine للعبة court
- [ ] جرد توزيع الأدوار والنقاط
- [ ] جرد هيكل القضايا
- [ ] تجربة جلسة 4 لاعبين
- [ ] تجربة جلسة 8 لاعبين
- [ ] توثيق نقاط التوقف الفعلية

**مخرجات:** مخطط المراحل + قائمة عيوب مؤكدة

---

### المرحلة 1 — تبسيط أول جلسة (يوم 3–7)
- [ ] خريطة تعليمات: role × phase (عربي/إنجليزي)
- [ ] بطاقة دور حية على جوال كل لاعب
- [ ] شريط مراحل على شاشة المضيف/العرض
- [ ] مقدمة اختيارية 30 ثانية قبل توزيع الأدوار

**المراحل المعتمدة:**  
قصة → أدلة 1 → استجواب 1 → أدلة 2 → استجواب 2 → مرافعة المدعي → مرافعة المحامي → تصويت → كشف

**إغلاق عند:** ظهور التعليمات لكل دور + شريط يعكس المرحلة والوقت

---

### المرحلة 2 — تخفيف عبء المضيف (يوم 6–10)
- [ ] انتقال تلقائي عند timer = 0
- [ ] زر تمديد 30 ثانية
- [ ] زر التالي مع ملخص المرحلة القادمة
- [ ] استدعاء المنصة: متهم / شاهد 1 / شاهد 2 / محقق
- [ ] عرض «الآن على المنصة» للجميع
- [ ] التحقق من hostMode داخل المحكمة

**أحداث المحرك:**  
advancePhase | extendTimer | callToStand | clearStand

---

### المرحلة 3 — تنشيط المحلفين والشهود (يوم 10–15)
- [ ] ملاحظة سرية للمحلف بعد كل جولة أدلة
- [ ] سؤال محلف واحد بالدور (اختياري)
- [ ] زر «اقترح سؤالًا» (3 اقتراحات)
- [ ] توازن معلومات الشهود (مؤكد + ملتبس)
- [ ] معلومة إضافية لبعض الأدوار في الجولة 2

---

### المرحلة 4 — دراما الكشف (يوم 14–18)
- [ ] تسلسل ثابت: انتظار → أرقام التصويت → الحكم → الحقيقة → الأدوار → النقاط
- [ ] أصوات: مطرقة / اعتراض / حكم
- [ ] ملخص نهاية الجلسة

---

### المرحلة 5 — بنك القضايا (بالتوازي يوم 12–25)

**هيكل القضية:**

```json
{
  "id": "court_case_001",
  "titleAr": "",
  "titleEn": "",
  "difficulty": "light",
  "durationMin": 20,
  "familyFriendly": true,
  "storyAr": "",
  "storyEn": "",
  "truth": "guilty",
  "evidence": [{ "round": 1, "textAr": "", "textEn": "" }],
  "roles": {
    "defendant": { "secretAr": "", "secretEn": "" },
    "prosecutor": { "secretAr": "", "secretEn": "" },
    "lawyer": { "secretAr": "", "secretEn": "" },
    "detective": { "secretAr": "", "secretEn": "" },
    "witnesses": [{ "secretAr": "", "secretEn": "" }]
  }
}
```

- [ ] اعتماد الهيكل
- [ ] تصنيف light / medium / deep + فلتر عائلي
- [ ] 12 قضية: 4 خفيفة + 5 متوسطة + 3 دسمة
- [ ] تضمين قضايا المتهم فيها بريء
- [ ] فحص جودة لكل قضية

---

### المرحلة 6 — الاعتراض والتصويت (يوم 18–21)
- [ ] عداد اعتراض ظاهر
- [ ] أثر بصري/صوتي + إيقاف 5–8 ثوانٍ
- [ ] سبب اختياري
- [ ] إظهار الأصوات بعد الإغلاق فقط
- [ ] الإبقاء على التعادل لصالح المتهم

---

### المرحلة 7 — لاحقًا فقط بعد الاستقرار
- [ ] وضع سريع 15 دقيقة
- [ ] مولّد AI → مسودة → اعتماد يدوي
- [ ] حزم ثيمات
- [ ] إحصاءات

- COURT-004 استدعاء المنصة

## 8) قرار البدء الافتراضي

**المسار الفوري:** المرحلة 0 → 1 → 2 خلال الأسبوع الأول، مع كتابة القضايا بالتوازي.

1. بطاقة دور حية حسب المرحلة
2. شريط مراحل
