# مراجعة الأمان، أكتوبر 2026

فحص للقاعدة الحية (wabduallah's Project) وللكود وللموقع المنشور. هذا الملف يذكر ما أُصلح في هذا الفرع، وما بقي ويحتاج قرارًا منك.

## أُصلح في هذا الفرع

| الثغرة | الخطورة | الإصلاح |
|---|---|---|
| مسار Better Auth القديم من قالب المشروع (`/api/auth/*`) شغّال في الإنتاج، ويسمح لأي شخص بإنشاء حساب بالبريد وكلمة مرور في جداول `users/session/account` | عالية | يرد 404 دائمًا، إلا إذا ضُبط `LEGACY_BETTER_AUTH=on` عن قصد |
| لا حد لإنشاء الغرف: أي جهاز يقدر يغرق القاعدة بآلاف الغرف | متوسطة | 30 غرفة في الساعة لكل مضيف (`site_v1.sql`)، والمدير مستثنى |
| 9 دوال بلا `search_path` ثابت (تنبيه فاحص Supabase) | منخفضة | ثُبّت `search_path = public` |
| زر الجرس كان يعرف اللاعب بطريقة مختلفة عن بقية الألعاب | منخفضة | صار يمر من `my_player_id` مثل كل الألعاب |

## سليم (فُحص)

- إجابات الأسئلة الصحيحة والمزيفة لا يقرؤها اللاعبون (لا صلاحية select على الأعمدة).
- أدوار المافيا وأفعال الليل وقضايا المحكمة ونتائجها والرسائل: للمدير والخادم فقط.
- لا أسرار في حالة الغرف التي تصل للجوالات.
- لا مفاتيح سرية في كود المتصفح. `.env.example` فقط في المستودع.
- `dangerouslySetInnerHTML` يُستعمل لأيقونات SVG ثابتة فقط. صفحات المعلومات الجديدة نص فقط، فلا يستطيع أحد حقن كود حتى من لوحة الإدارة.
- روابط التواصل التي يكتبها المدير تُنظَّف قبل عرضها (بريد صحيح، أرقام فقط لواتساب، أسماء حسابات فقط).
- الرسائل لها حد إرسال.

## باقٍ ويحتاج قرارك

1. **قراءة الغرف واللاعبين مفتوحة (متوسطة).** `game_rooms` و `room_players` يقرؤها أي زائر، فيقدر شخص يسرد رموز الغرف المفتوحة وأسماء اللاعبين ويدخل غرف الغرباء. الطرد والمنع يخففان الضرر. الحل الأفضل: دالة تبحث عن الغرفة بالرمز فقط، وقصر القراءة على أعضاء الغرفة. تغيير كبير يمس كل الألعاب، فيحتاج فرعًا مستقلًا واختبارًا كاملًا.
2. **رؤوس الحماية ناقصة (متوسطة).** الموقع يرسل `X-Content-Type-Options` فقط. لم أغيّر إعدادات النشر. المقترح في `vercel.json`:
   ```json
   {
     "headers": [{
       "source": "/(.*)",
       "headers": [
         { "key": "Strict-Transport-Security", "value": "max-age=63072000; includeSubDomains; preload" },
         { "key": "X-Frame-Options", "value": "SAMEORIGIN" },
         { "key": "Referrer-Policy", "value": "strict-origin-when-cross-origin" },
         { "key": "Permissions-Policy", "value": "camera=(), microphone=(), geolocation=()" }
       ]
     }]
   }
   ```
   وبعد التجربة: `Content-Security-Policy` يسمح فقط بالموقع نفسه و Supabase و Google Fonts.
3. **الدخول المجهول بلا تحقق من البشر (متوسطة).** فعّل CAPTCHA (Cloudflare Turnstile) من Supabase → Authentication → Attack Protection، ثم نضيف الويدجت في الموقع.
4. **حساب المدير (متوسطة).** فعّل التحقق بخطوتين (MFA) لحساب المدير، وحماية كلمات المرور المسرّبة (Leaked password protection) من Supabase → Authentication.
5. **جداول Better Auth القديمة في القاعدة** (`users`, `session`, `account`, `verification`): فارغة وغير مستعملة. حذفها قرارك؛ لم ألمسها.
6. **تنظيف (منخفضة):** `src/pages/api` كود Next.js قديم لا يُستعمل، و `migrations/20261015_*` لا تطابق قاعدة Supabase ولم تُشغَّل. ودالة `court-generate` غير منشورة.
